# Evidencias de TaskManager - Actividad Integradora 2

**Proyecto:** Mi TaskManager - Programacion de Sistemas Web (ECOTEC, 2026)

Estas capturas fueron tomadas durante el desarrollo, las pruebas en localhost,
la integracion de la API de ejemplo, el trabajo offline y la publicacion de GitHub.
No son recreaciones: se conservaron las capturas originales.

## Guia rapida
- Para subir evidencias a GitHub, usa el ZIP `TaskManager_Evidencias_Seleccionadas_Para_GitHub.zip`.
- Descomprime su contenido en la raiz local de `C:\xampp\htdocs\taskmanager-eduardo`.
- Debe quedar `taskmanager-eduardo/docs/evidencias/...` (sin duplicar la carpeta del proyecto).
- Luego abre GitHub Desktop, haz commit de los archivos nuevos y usa **Push origin**.
- Si deseas conservar el recorrido entero de la actividad, usa el ZIP completo de 49 capturas en vez del seleccionado.

## Sobre las pruebas
- El JSONPlaceholder entrego inicialmente 200 tareas, como muestran las evidencias de API.
- En la version personalizada se presentan 12 ejemplos en espanol vinculados con datos de la API.
- El navegador normal y el modo incognito pueden mostrar cantidades diferentes porque localStorage guarda los datos en cada perfil/origen.
- La captura 49 muestra las 200 tareas antiguas que ese navegador tenia guardadas, no un fallo ni una carga nueva.
- Las capturas con errores se conservaron como parte de la depuracion, no como prueba de que ese error permanezca.
